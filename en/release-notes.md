## Network > Load Balancer(DSR) > Release Notes

### May 27, 2026

#### Added Features

* A new Load Balancer (DSR) service has been added. Provides a load balancer service that operates using the Direct Server Return (DSR) method.
	* Load Balancer (DSR) is available only in the Korea (Pyeongchon) and Korea (Pangyo) regions.
* See the [Load Balancer(DSR) Console User Guide](/Network/Load%20Balancer(DSR)/en/console-guide/) for more information.
